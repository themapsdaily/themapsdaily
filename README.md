# Hi, I'm Siddharth

I run [TheMapsDaily](https://themapsdaily.com), where India's public data becomes maps, charts and short stories that anyone can read. I also build the tools behind them and share the reusable parts as open source.

## What I share here

| Project | What it does |
|---|---|
| [india-choropleth-maps](https://github.com/themapsdaily/india-choropleth-maps) | Turns a table of numbers into a colour-shaded map of Indian states, districts or constituencies, with notebooks that run in Google Colab. |
| [spiral-bar-charts](https://github.com/themapsdaily/spiral-bar-charts) | Draws a ranked list as a spiral bar chart, with an optional social card. |
| [city-poster-maps](https://github.com/themapsdaily/city-poster-maps) | Makes a poster-style map of any city or neighbourhood from OpenStreetMap. |
| [themapsdaily-relief-maps](https://github.com/themapsdaily/themapsdaily-relief-maps) | Turns any Indian state into a 3D shaded-relief map, ready to post as a vertical story. Built in R. |
| [india-3d-terrain-maps](https://github.com/themapsdaily/india-3d-terrain-maps) | Interactive 3D terrain maps of Himachal Pradesh and Goa that run in a web browser. |
| [themapsdaily-data-explorer](https://github.com/themapsdaily/themapsdaily-data-explorer) | The first working version of our data explorer, with interactive charts and state maps. |
| [firetv-launcher](https://github.com/themapsdaily/firetv-launcher) | An Apple TV style home screen for the Amazon Fire TV Stick, plus a safe, reversible debloat script. |
| [samsung-watch-launcher](https://github.com/themapsdaily/samsung-watch-launcher) | A simple home screen for a Samsung Galaxy Watch, plus a safe, reversible debloat script. |
